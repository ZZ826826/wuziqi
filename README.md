# 局域网五子棋（wuziqi）

两人在同一局域网内直连对弈的五子棋，纯网页单文件，无需服务器、无需账号、无需安装环境。基于 WebRTC DataChannel 点对点通信，连接信息经压缩短码手动交换。

## 玩法

- 15×15 棋盘，黑棋先行，轮流落子。
- 横、竖、斜任意方向先连成五子者胜；棋盘下满未分胜负为平局。
- 支持认输、重新开局、双方比分统计、对局实时聊天。

## 如何连接（两人同一 Wi-Fi / 路由器）

1. 两人各自用浏览器打开 `gomoku.html`（双击即可）。
2. 一人点「我来创建对局（执黑先手）」→「生成邀请」，把邀请短码整段复制发给对方。
3. 另一人点「我加入对局（执白后手）」→ 粘贴邀请短码 →「生成应答」，把应答短码回传。
4. 创建方粘贴应答短码 →「完成连接」，即可落子。

> 连接走 WebRTC 点对点，不经过任何中转服务器；若一次未通，重新生成邀请再试。

## 特性

- 单文件 HTML，CSS/JS 全部内联，无外部依赖（字体走 CDN，断网可回退系统字体）。
- WebRTC 手动信令，SDP 经 deflate-raw 压缩为短码，兼容明文粘贴。
- 对局聊天、认输、重开、比分、最后一手标记、五子连珠高亮。
- 一键躲避的按钮可直接关闭网页！！！！！

## 技术

- 原生 JavaScript + Canvas 2D 绘制棋盘。
- `RTCPeerConnection` + `RTCDataChannel` 点对点。
- `CompressionStream` / `DecompressionStream` 压缩信令短码。
- 无构建步骤，直接浏览器打开。

## 使用

直接用浏览器打开 `gomoku.html` 即可开始。
